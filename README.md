# Təmir Reyestri

Təmir zavodlarına daxil olan texnikanın qəbulu, təmiri və təhvilinin uçotu. C# WinForms (.NET 8), lokal SQLite bazası, şifrəli USB ilə məlumat ötürmə, AZ / EN / RU, işıqlı və qaranlıq tema.

## Visual Studio-da açmaq

1. **Visual Studio 2022** (17.13+) və **".NET desktop development"** komponenti quraşdırın.
2. `TexnikaReyestri.slnx` faylını açın.
3. **Build → Build Solution** (`Ctrl+Shift+B`) — NuGet paketləri avtomatik yüklənir.
4. **F5** — proqram işə düşür. İlk açılışda "İlk quraşdırma" pəncərəsi çıxır.
